# 团队开发简要说明

这份文档只说明团队开发时最容易踩坑的几件事：项目文件在哪里、配置怎么处理、服务器上怎么运行。

## 1. 项目目录

项目根目录：

```text
/opt/agentForMaterial/source
```

主要目录：

```text
admin/      后端启动入口和配置文件
common/     后端通用工具
framework/  后端框架配置，比如权限、Redis、MyBatis、Druid
system/     主要业务代码，比如用户、角色、文档、标签、OSS 上传
quartz/     定时任务
generator/  代码生成模块
sql/        数据库初始化和变更 SQL
ui/         前端 Vue 项目
deploy/     服务器部署相关文件
```

后端启动类：

```text
admin/src/main/java/com/ruoyi/RuoYiApplication.java
```

后端主要配置：

```text
admin/src/main/resources/application.yml
admin/src/main/resources/application-druid.yml
```

前端目录：

```text
ui/
```

## 2. 不要把密钥写进代码

以后不要再把这些内容直接写死到代码里：

```text
数据库密码
阿里云 OSS Key
百度 OCR Key
Token Secret
```

代码配置文件里只保留环境变量占位符，例如：

```yml
password: ${DB_PASSWORD}
keyid: ${ALIYUN_OSS_KEY_ID:}
keysecret: ${ALIYUN_OSS_KEY_SECRET:}
key: ${BAIDU_API_KEY:}
secret: ${BAIDU_API_SECRET:}
```

每个人本地电脑自己配置自己的环境变量。Windows PowerShell 示例：

```powershell
[Environment]::SetEnvironmentVariable("RUOYI_PROFILE", "D:/ruoyi/uploadPath", "User")
[Environment]::SetEnvironmentVariable("DB_URL", "jdbc:mysql://localhost:3306/aiforscience?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai", "User")
[Environment]::SetEnvironmentVariable("DB_USERNAME", "root", "User")
[Environment]::SetEnvironmentVariable("DB_PASSWORD", "替换为本机数据库密码", "User")
[Environment]::SetEnvironmentVariable("TOKEN_SECRET", "替换为足够长的随机字符串", "User")
[Environment]::SetEnvironmentVariable("DRUID_USERNAME", "ruoyi", "User")
[Environment]::SetEnvironmentVariable("DRUID_PASSWORD", "替换为监控页面强密码", "User")
[Environment]::SetEnvironmentVariable("BAIDU_API_KEY", "替换为百度OCR Key", "User")
[Environment]::SetEnvironmentVariable("BAIDU_API_SECRET", "替换为百度OCR Secret", "User")
[Environment]::SetEnvironmentVariable("ALIYUN_OSS_ENDPOINT", "oss-cn-shanghai.aliyuncs.com", "User")
[Environment]::SetEnvironmentVariable("ALIYUN_OSS_KEY_ID", "替换为阿里云OSS Key ID", "User")
[Environment]::SetEnvironmentVariable("ALIYUN_OSS_KEY_SECRET", "替换为阿里云OSS Key Secret", "User")
[Environment]::SetEnvironmentVariable("ALIYUN_OSS_BUCKET", "替换为OSS Bucket", "User")
```

配置完环境变量后，要彻底重启 IntelliJ IDEA，否则 IDEA 可能读不到新变量。

服务器上的真实配置放在：

```text
/etc/default/agent-material
```

不要把这个文件不要提交到 Git。

## 3. 服务器上项目在哪里

服务器源码目录：

```text
/opt/agentForMaterial/source
```

后端 jar：

```text
/opt/agentForMaterial/backend/ruoyi-admin.jar
```

前端静态文件：

```text
/var/www/agentForMaterial
```

服务器环境变量：

```text
/etc/default/agent-material
```

后端服务名：

```text
agent-material
```

## 4. 服务器怎么运行和重启

查看后端状态：

```bash
sudo systemctl status agent-material
```

重启后端：

```bash
sudo systemctl restart agent-material
```

查看后端日志：

```bash
journalctl -u agent-material -f
```

查看 Nginx 状态：

```bash
sudo systemctl status nginx
```

重载 Nginx：

```bash
sudo systemctl reload nginx
```

## 5. 服务器更新项目

更新后端：

```bash
cd /opt/agentForMaterial/source
mvn clean package -DskipTests

sudo systemctl stop agent-material
sudo cp admin/target/ruoyi-admin.jar /opt/agentForMaterial/backend/ruoyi-admin.jar
sudo chown agentmat:agentmat /opt/agentForMaterial/backend/ruoyi-admin.jar
sudo systemctl start agent-material
```

更新前端：

```bash
cd /opt/agentForMaterial/source/ui
npm install
npm run build:prod

sudo rm -rf /var/www/agentForMaterial/*
sudo cp -r dist/* /var/www/agentForMaterial/
sudo systemctl reload nginx
```

验证后端：

```bash
curl http://127.0.0.1/prod-api/captchaImage
```

能返回验证码 JSON，说明后端和 Nginx 基本正常。
